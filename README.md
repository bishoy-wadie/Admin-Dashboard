# Admin Dashboard

This is an Angular-based Admin Dashboard application designed for managing and monitoring data effectively. The project uses Tailwind CSS for styling and Express for server-side rendering (SSR).

## Features

- Responsive UI with Angular Material and Tailwind CSS.
- Notification system using `ngx-toastr`.
- Server-Side Rendering (SSR) support.
- Modular and scalable code structure.

---

## Prerequisites

Before running the application, ensure you have the following installed:

- **Node.js** (version 18.x or higher)
- **Angular CLI** (globally installed)

---

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-link>
   cd Admin-Dashboard-develop
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

---

## Running the Application Locally

### 1. Development Mode

To run the application in development mode:

```bash
npm start
```

This will start the development server at `http://localhost:4200/`.

## Project Structure

- **src/**: Contains the main application source code.
- **public/**: Static assets.
- **server.ts**: Backend server file for SSR.
- **angular.json**: Angular CLI configuration file.
- **tailwind.config.js**: Configuration for Tailwind CSS.

---

## Dependencies

### Main Dependencies:

- Angular Framework (`@angular/*`)
- Express (for SSR)
- `ngx-toastr` (notifications)
- `rxjs` (reactive programming)

### Development Dependencies:

- Tailwind CSS (`tailwindcss`, `daisyui`)
- TypeScript
- Karma and Jasmine (testing tools)

---

## Styling

This project uses Tailwind CSS with DaisyUI for a modern and responsive design. You can configure styles in `tailwind.config.js`.
